Customer Account Takeover Detection

A machine learning system designed to identify potentially compromised customer accounts.

01

The problem

Customer accounts can be compromised through suspicious authentication and account activity.

This project uses machine learning to classify account activity as normal or potentially compromised.

02

The approach

Supervised classification, compared across three models.

The objectives of the project:

  1. 1Analyze customer account activity data.
  2. 2Identify patterns associated with account takeover.
  3. 3Train supervised classification models.
  4. 4Compare the performance of different models.
  5. 5Develop a Flask-based prediction system.
03

The technology

Built with Python and Flask.

PythonFlaskJavaScriptHTMLCSSMachine Learning

Logistic Regression

A linear model that estimates the probability that an account belongs to the compromised class. Simple, fast and easy to interpret, so it works well as a baseline.

Decision Tree

Splits the data with a series of if-then rules on account features. The tree is easy to read and shows how a decision was reached, but a single tree can overfit.

Random Forest

Combines many decision trees trained on different samples and averages their votes. Usually more accurate and stable than a single tree, and it can rank feature importance.
