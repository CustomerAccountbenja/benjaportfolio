Overview

Understanding human language

What is NLP?

Natural Language Processing (NLP) is a branch of Artificial Intelligence (AI) that enables computers to understand, interpret, analyse and process human languages such as English, French and other languages.

NLP combines linguistics, computer science and machine learning to support tasks such as text summarisation, keyword extraction, language detection, sentiment analysis and text classification.

In simple terms: NLP enables computers to understand and work with human language, making communication between people and machines easier.

NLP Smart Analyzer applies these ideas in a Flask web application. Users can paste text or upload a document, choose an available analysis, and review the result in the browser. The repository also documents authenticated analysis history and API endpoints.

Capabilities

From document to insight

Features documented in the project repository.

Keyword extraction

Find key terms and phrases with TF-IDF, RAKE and YAKE methods.

Text summarisation

Generate extractive or abstractive summaries of submitted text.

Language detection

Identify the language of submitted text for multilingual workflows.

Sentiment analysis

Analyse sentiment using VADER, with optional multilingual model support.

Document processing

Upload text, PDF or DOCX files and extract their content for analysis.

Translation and history

Translate text and revisit previous analyses from the user workspace.

My contribution

Building the application

I developed the Flask application and its user-facing text-analysis workflow, integrating NLP tools for keyword extraction, summarisation, language detection, sentiment analysis and document processing. The project also brings together user authentication, analysis history and API functionality.

The repository includes setup instructions and automated tests. Its documented test command is pytest.
