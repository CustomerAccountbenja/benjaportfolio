Overview

Understanding human language

What is NLP?

Natural Language Processing (NLP) is a branch of Artificial Intelligence (AI) that enables computers to understand, interpret, analyse and process human languages such as English, French and other languages.

NLP combines linguistics, computer science and machine learning to support tasks such as text summarisation, keyword extraction, language detection, sentiment analysis and text classification.

In simple terms: NLP enables computers to understand and work with human language, making communication between people and machines easier.

NLP Smart Analyzer applies these ideas in a Flask web application. Users sign in to a private workspace, paste text or upload a document, run one of six analysis tools, and review the result in the browser. Authenticated analysis history, downloadable PDF reports, an admin panel and JSON API endpoints support the wider workflow.

Capabilities

From document to insight

Six analysis tools, a document workflow and the account features that tie them together.

Keyword extraction

Find key terms and phrases with TF-IDF, RAKE and YAKE methods.

Text summarisation

Generate extractive or abstractive summaries of submitted text.

Language detection

Identify the language of submitted text for multilingual workflows.

Sentiment analysis

Analyse sentiment using VADER, with optional multilingual model support.

Text explanation

Simplify difficult passages using local models or OpenAI-compatible APIs.

Translation

Translate text through MyMemory, LibreTranslate, OpenAI-compatible endpoints or local models.

Document processing

Upload text, PDF or DOCX files and extract their content for analysis.

PDF report export

Combine up to twelve analyses into a downloadable PDF report.

Admin and security

Manage users and roles with CSRF protection, rate limiting and hardened headers.

How it was measured

A reproducible benchmark

The evaluation harness runs the live algorithms over fixed, seeded datasets and records per-class and per-document results alongside mean latency and summary compression. Keyword extraction is scored with strict and soft matching; summarisation uses stemmed ROUGE and BLEU-4. The labelled sets are deliberately small, so the figures are indicative of behaviour rather than production-grade claims.

My contribution

Building the application

I built the application end to end: the Flask backend and JSON API, the server-rendered workspace and its six NLP tools, the document extraction pipeline, PDF report generation, authentication, per-user history and the admin panel.
