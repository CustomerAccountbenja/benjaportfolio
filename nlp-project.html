Overview

Understanding human language.

Natural Language Processing (NLP) is a branch of artificial intelligence that enables computers to understand, interpret, analyse and process human language. It combines linguistics, computer science and machine learning to support tasks such as summarisation, keyword extraction, language detection and sentiment analysis.

In simple terms: NLP enables computers to understand and work with human language, making communication between people and machines easier.

NLP Smart Analyzer applies these ideas in a Flask web application. Users sign in to a private workspace, paste text or upload a document, run one of six analysis tools, and review the result in the browser. Authenticated analysis history, downloadable PDF reports, an admin panel and JSON API endpoints support the wider workflow.

How it was measured

A reproducible benchmark.

The evaluation harness runs the live algorithms over fixed, seeded datasets and records per-class and per-document results alongside mean latency and summary compression.

Keyword extraction is scored with strict and soft matching; summarisation uses stemmed ROUGE and BLEU-4. The labelled sets are deliberately small, so the figures are indicative of behaviour rather than production-grade claims.

My contribution

Building the application.

I built the application end to end: the Flask backend and JSON API, the server-rendered workspace and its six NLP tools, the document extraction pipeline, PDF report generation, authentication, per-user history and the admin panel. I also added the evaluation harness that benchmarks each feature and wrote the test suite.

The repository includes setup instructions, a reproducible evaluation script and 118 automated pytest tests covering authentication, uploads, analysis endpoints, reporting and security expectations.
